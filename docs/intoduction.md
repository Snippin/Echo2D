# Introduction

Echo2D is a simple 2d game engine that I am creating to practice my skills and
learn.

## Libraries/Technologies Used

|    Name     | Description                                                           |
| :---------: | --------------------------------------------------------------------- |
|   [entt]    | Fast and reliable entity component system                             |
|   [SDL2]    | Abstraction layer for audio, graphics, and, input hardware components |
| [SDL_mixer] | Support for various file formats to SDL                               |
|    [glm]    | Math library for graphics software                                    |
|   [sol3]    | Lua API wrapper with advanced features and top notch performance      |
|    [stb]    | Single-file public domain libraries                                   |
|    [fmt]    | Modern formatting library                                             |
|    [Lua]    | Powerful, efficient, lightweight, embeddable scripting language       |

[entt]: https://github.com/skypjack/entt
[SDL2]: https://github.com/libsdl-org/SDL
[SDL_mixer]: https://github.com/libsdl-org/SDL_mixer
[glm]: https://github.com/g-truc/glm
[sol3]: https://github.com/ThePhD/sol2
[stb]: https://github.com/nothings/stb
[fmt]: https://github.com/fmtlib/fmt
[Lua]: https://www.lua.org/
